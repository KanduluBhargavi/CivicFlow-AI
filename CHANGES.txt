CivicFlow AI root route fix
============================

Replace D:\CivicFlow-AI\backend\app\main.py with this main.py after backing up
your current file.

This version:
- Explicitly returns frontend/index.html for GET / instead of the JSON welcome text.
- Uses one path resolver for both the root page and static assets.
- Logs [frontend] serving ... when static mounting succeeds.
- Does not change .env, credentials, database logic, model code, or API routers.

Expected layout:
  D:\CivicFlow-AI\frontend\index.html
  D:\CivicFlow-AI\backend\app\main.py

After replacing:
1. Stop Uvicorn with Ctrl+C.
2. From D:\CivicFlow-AI\backend run:
     .\venv\Scripts\Activate.ps1
     uvicorn app.main:app --reload
3. Open http://127.0.0.1:8000/

The patch passed a Python syntax check but has not been integration-tested against the
complete local project. Keep existing .env files and credentials unchanged.
